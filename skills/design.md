# Design Skill

## Goal

Create a professional developer portfolio that feels intentional and distinctive rather than like a generic AI-generated template.

## Design Priorities

Prioritize:

1. Typography
2. Layout
3. Spacing
4. Visual hierarchy
5. Readability
6. Content
7. Subtle visual details

## Avoid

Do not overuse:

- gradients
- glassmorphism
- glowing effects
- excessive rounded cards
- floating elements
- huge decorative text
- excessive animations
- unnecessary icons

Do not make the site look like a generic AI SaaS landing page.

## Developer Identity

The design should communicate:

- technical competence
- professionalism
- personality
- trust
- attention to detail

The content should be more important than decoration.

## Typography

Use a clear typographic hierarchy.

Ensure:

- readable body text
- appropriate line length
- strong headings
- consistent spacing

Do not use extremely small text for important information.

## Layout

Use a consistent spacing system.

Maintain comfortable content widths.

Avoid excessively wide text blocks.

## Responsive Design

Design mobile-first.

Test:

- mobile
- tablet
- desktop
- large desktop

Do not simply shrink the desktop design for mobile.

## Interaction

Interactions should have a purpose.

Buttons and links should clearly communicate their action.

Use hover states where appropriate.

Ensure keyboard users receive visible focus states.

## Animation

Animations must be:

- subtle
- purposeful
- performant

Respect:

`prefers-reduced-motion`

Never make animation necessary to understand content.

## Consistency

Maintain consistency for:

- buttons
- links
- cards
- spacing
- typography
- borders
- navigation
- page headers

## Rule

When deciding between a decorative effect and better usability, choose usability.
