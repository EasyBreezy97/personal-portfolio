1. Understand the task and existing architecture.
2. Review the entire change/diff.
3. Look for:
   - bugs
   - security issues
   - TypeScript problems
   - Next.js mistakes
   - SEO regressions
   - accessibility issues
   - performance problems
   - unnecessary dependencies
   - duplicated/overcomplicated code
4. Never invent personal/content information.
5. Fix Critical and High issues.
6. Fix reasonable Medium issues.
7. Don't waste time on trivial style changes.
8. Run:
   - TypeScript
   - ESLint
   - tests
   - production build
9. Review the final diff again.
10. Report:

- what was reviewed
- problems found
- fixes made
- validation results
- remaining issues
